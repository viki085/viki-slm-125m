The goal of this project Is to create an SLM 125M model that is an expert Data Scientist / coder in Python and SQL. That can be used in an agentic AI application. This model will be used to analyze and interpret data and provide insights to the users. It will also be used to generate code to perform various data analysis tasks. The model Should be able to understand the user's query Generate an SQL script that can be executed by an agentic system to query and retrieve data from the database.  Analyze the retrieved data and provide insights to the users in a clear and concise manner.It should also be able to perform basic data analysis tasks by writing code into notebooks, executing, and training the system using the agentic function.

Before we go on to create the entire agentic application, we need to create the SLM 125 million model. This will be a open source model that can be used by anyone to create their own agentic AI applications. I also feel that it should be able to answer or act as an SME on either supply chain management systems or financial systems and banking systems. I will leave it up to you to decide if the model needs to be pre-trained on knowledge for these topics or if we can fine-tune them.

Based on the idea that I have provided above, I want you to Look at the reference.md (reference.md) file And create a similar document that can be used for creating SLM 125M model. The document will serve as a guide for creating the model.
