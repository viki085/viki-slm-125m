Small model, handle with care. It writes plausible SQL and code that can still be wrong, so check the generated query and result before relying on them. Chat answers can be inaccurate or invented. It is not a source of financial or business advice.
Built from scratch with a streamed data pipeline, a custom 32K tokenizer, 8×H100 pretraining on Modal, and local supervised fine-tuning. See the project README and docs/DECISIONS.md for the full record.
